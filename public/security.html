Security & wallet safety

evm.market is a Base NFT collection explorer for Base Punks and NodeMonkes. This page describes the wallet permissions and the boundaries of the marketplace experience.

Never share your Secret Recovery Phrase or private key. evm.market will never ask you to enter them into this site.

What wallet connection does

  • Connection requests access to the public wallet account you choose.
  • The site reads the wallet's current network and performs a read-only ownership check for an NFT when needed.
  • Connection does not ask you to sign a message or send a blockchain transaction.
  • The site does not switch networks automatically. If your wallet is not on Base mainnet (chain ID 8453), change networks yourself in the wallet.

Marketplace actions

Buy, Make offer, Sell and List links open an external marketplace. The external marketplace may request signatures, approvals or transactions. Before accepting any wallet prompt, verify the collection contract, token ID, recipient, total price, fees, expiration and permission scope. Reject prompts you do not understand.

The supported collection contracts are:

  • Base Punks: 0xb9110ba3266f4983193c0d5f55c792a94368af28
  • NodeMonkes: 0x095b6ae2102094be8b5f06fac27275ddb9a8c70a

Security reports and warnings

If your wallet or browser flags this domain, do not bypass the warning or sign anything. Please report the exact warning text, the wallet/browser name and version, the page URL and a screenshot with personal information removed through the wallet provider's official support channel. Do not include seed phrases, private keys or sensitive wallet data.

For a possible MetaMask false positive, see the official MetaMask phishing-detection repository and its domain review guidance. A site owner cannot remove a warning from a wallet's reputation system by changing website code alone; the relevant provider must review and clear the classification.

Third-party services

NFT artwork and metadata may be served by third-party providers, and trading links lead to external marketplaces. Those services have their own security policies and wallet prompts. evm.market does not operate a native exchange contract and does not execute marketplace orders itself.
