Security & wallet safety

evm.market is an EVM NFT collection explorer for Base Punks, NodeMonkes, BYTEBEASTS, CryptoPunks [Base] and NodeMonkes [Polygon]. This page describes wallet permissions and the boundaries of the marketplace experience.

Never share your Secret Recovery Phrase or private key. evm.market will never ask you to enter them into this site.

What wallet connection does

  • Connection requests access to the public wallet account you choose.
  • The site reads the wallet's current network and performs a read-only ownership check when requested.
  • To verify a session, the site asks for a one-time message signature; this is not a blockchain transaction and does not grant token/NFT approvals.
  • Wallet sign-in may request Base mainnet (chain ID 8453). Polygon market actions require Polygon mainnet (chain ID 137); an action can ask permission to switch the wallet network before any transaction is prepared.

Marketplace actions

The collection's external marketplace link opens Rarible for NodeMonkes [Polygon] and OpenSea or Rarible for Base collections. evm.market also provides Seaport actions through OpenSea's API where supported. Approvals, order signatures, purchases and cancellations are separate wallet prompts. Review the chain, NFT contract, token ID, recipients, total price, fees, expiry and approval scope before accepting. Reject prompts you do not understand.

NodeMonkes [Polygon] is linked to Rarible for browsing; Rarible orders are not read or executed in-app. No OpenSea collection slug has been verified for this Polygon contract, so the site does not claim its OpenSea orderbook is complete. If no compatible OpenSea order is returned, use the Rarible marketplace link.

Security reports and warnings

If your wallet or browser flags this domain, do not bypass the warning or sign anything. Please report the exact warning text, the wallet/browser name and version, the page URL and a screenshot with personal information removed through the wallet provider's official support channel. Do not include seed phrases, private keys or sensitive wallet data.

For a possible MetaMask false positive, see the official MetaMask phishing-detection repository and its domain review guidance. A site owner cannot remove a warning from a wallet's reputation system by changing website code alone; the relevant provider must review and clear the classification.

Third-party services

NFT artwork and metadata may be served by third-party providers, and marketplace actions depend on OpenSea and the user's connected wallet. Rarible links leave evm.market for that marketplace. These services have their own policies and wallet prompts. evm.market does not operate an exchange contract, hold a user's keys, or sign orders on the user's behalf.
